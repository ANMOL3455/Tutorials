Lesson: Tables in HTML

Today, we are going to learn how to create tables in HTML.

Step 1: Basic Table

First, we create a simple table using the <table> tag.

We are doing this:

<table border="2px">
    <tr>
        <th>SN</th>
        <th>NAME</th>
        <th>CLASS</th>
    </tr>
</table>

Explanation:

  • <table> → creates the table
  • <tr> → table row
  • <th> → table heading
  • <td> → table data

Result:

Class Details
SN NAME CLASS
1 anmol 12
2 manish 13

Step 2: Table with More Data

Now, we create a bigger table with more columns.

We are adding: name, post, address, and salary.

Result:

Employee Details
SN NAME POST ADDRESS SALARY
1 anmol security kathmandu 230000
2 manish developer lolang 230000

We can also use <tfoot> for summary:

Item Value
Salary 230000
Average Salary: 55000

Step 3: Rowspan and Colspan

Now, we learn how to merge rows and columns.

  • rowspan → merges rows
  • colspan → merges columns

Result:

Product Flavors
Milk Almond
Mango
Guava
Chocolate Banana
These are exclusive flavors

Step 4: Complex Table

Finally, we create a more complex table using both rowspan and colspan.

Result:

Students Details
Heading Students Details
ID NAME DEPARTMENT ROLL NO
Students 1 victor science 1234
2 williams chemistry 12345
3 harry physics 123
4 rick cs 12

Final Notes

  • Use <th> for headings and <td> for data
  • Use rowspan to merge rows
  • Use colspan to merge columns
  • Use <caption> to give your table a title
