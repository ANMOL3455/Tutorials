Lesson: Lists in HTML

Today, we are going to learn about the three types of lists in HTML.

Step 1: Ordered List (ol)

Ordered lists are used when order or priority matters.

We are doing this:

<ol type="i">
    <li>mango</li>
    <li>banana</li>
</ol>

Result:

Serial list (roman numbers):

  1. mango
  2. banana
  3. peach
  4. litchi
  5. papaya

Reversed list:

  1. mango
  2. banana
  3. peach
  4. litchi
  5. papaya

Custom start list:

  1. mango
  2. banana
  3. peach
  4. litchi
  5. papaya

Step 2: Unordered List (ul)

Unordered lists are used when order does not matter. They show bullet points.

We are doing this:

<ul>
    <li>item</li>
</ul>

Result:

  • hari
  • saili
  • gairi
  • sudip
  • manish

Step 3: Description List (dl)

Description lists are used to explain terms.

  • <dt> → term
  • <dd> → description

Result:

int
whole numbers
string
collection of characters
float
decimal numbers

Step 4: Nested List

We can also create lists inside another list. This is called a nested list.

Result:

  1. Subjects
    1. maths
    2. science
    3. literature
  2. Programming Languages
    1. C
    2. Java
    3. Python
    4. Ruby
    5. Swift
  3. Computer Science Concepts
    1. data structures
    2. algorithm
    3. OS
    4. database management
    5. networking
  4. Web Tech
    1. HTML
    2. CSS

Final Notes

  • Use <ol> for ordered lists
  • Use <ul> for unordered lists
  • Use <dl> for descriptions
  • Always place nested lists inside <li>
  • <caption> is not used in lists (only for tables)
