Lesson: Inserting Media in HTML

Today, we are going to learn how to add audio and video to a webpage using HTML.

🎧 Step 1: Adding Audio

First, we will insert an audio file using the <audio> tag.

We are doing this:

<audio src="audio.mp3" controls preload="metadata"></audio>

Explanation:

  • src → the path of the audio file
  • controls → shows play and pause buttons
  • preload="metadata" → loads basic information only (recommended)

Step 2: Adding Video

Now, we will insert a video using the <video> tag.

We are doing this:

<video src="video.mp4" controls preload="metadata" width="600px"></video>

Explanation:

  • src → the path of the video file
  • controls → shows play and pause buttons
  • width → sets the size of the video
