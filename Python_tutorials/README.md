# Python Programming Tutorials

A practical Python learning collection from absolute beginner fundamentals through file handling, exceptions, modules, OOP, generators, decorators, JSON/CSV, virtual environments, and beginner projects.

## Folder structure

- 01_basics - variables, data types, conversion, comments
- 02_input_output - input, print, formatting
- 03_operators - arithmetic, comparison, logical, assignment, membership, identity, bitwise
- 04_conditionals - if, elif, else, nested conditions, match, truthy/falsy
- 05_loops - for, while, break, continue, nested loops, common exercises
- 06_functions - parameters, return values, defaults, *args, **kwargs, scope, recursion
- 07_data_structures - lists, tuples, sets, dictionaries, stacks, queues
- 08_strings - methods, formatting, searching, reversing, palindrome, counting
- 09_files - reading, writing, appending, modes, pathlib, copying files
- 10_exceptions - try/except, else/finally, raise, custom exceptions
- 11_modules_packages - imports, modules, __main__, package layout
- 12_oop - classes, objects, attributes, methods, inheritance, polymorphism, encapsulation
- 13_comprehensions_generators - comprehensions, generator expressions, yield
- 14_decorators - decorators, arguments, functools.wraps
- 15_lambda_map_filter - lambda, map, filter, reduce
- 16_json_csv - JSON and CSV read/write
- 17_datetime_math_random - useful standard-library modules
- 18_virtual_environment - venv and requirements
- 19_mini_projects - small practical programs

## Linux quick start

Check Python:

    python3 --version

Run a program:

    python3 01_basics/01_hello_world.py

From the tutorial root, for example:

    cd ~/path/to/Python_tutorials
    python3 05_loops/09_prime_check.py

## Virtual environment

Create one inside a project:

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install --upgrade pip
    python -m pip install requests
    python -m pip list
    deactivate

## Recommended learning order

Study the folders from 01 through 19. Do not rush. Type the examples yourself, change values, predict the output, and then run them.

## Learning philosophy

Learn -> Practice -> Build -> Improve

After every topic, make a small modification or mini program. The goal is not only to read Python syntax, but to develop programming logic and problem-solving ability.
