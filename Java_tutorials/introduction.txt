============================================================
                    JAVA PROGRAMMING
                    INTRODUCTION
============================================================


1. WHAT IS JAVA?
----------------

Java is a high-level, general-purpose, object-oriented
programming language.

Java was originally developed at Sun Microsystems. It was
designed by James Gosling and his team and was first released
in 1995.

Java is widely used for developing applications, backend
systems, enterprise software, desktop applications, Android
applications, web applications, and many other types of
software.

One of the main ideas behind Java is:

        "Write Once, Run Anywhere"

This means Java programs can run on different operating
systems through the Java Virtual Machine (JVM).


------------------------------------------------------------
2. WHY IS JAVA CALLED PLATFORM INDEPENDENT?
------------------------------------------------------------

Normally, programs compiled for one operating system may not
directly run on another operating system.

Java works differently.

Java source code is first compiled into BYTECODE.

        Java Source Code
               |
               v
          Java Compiler
             javac
               |
               v
          Bytecode
           .class
               |
               v
             JVM
               |
       -----------------
       |       |       |
     Linux  Windows  macOS

The JVM interprets or compiles the bytecode for the specific
operating system.

Therefore, the same Java bytecode can run on different
platforms when a suitable JVM is available.


------------------------------------------------------------
3. JAVA SOURCE CODE
------------------------------------------------------------

Java source code is written in files ending with:

        .java

Example:

        Hello.java

The Java compiler converts the source code into bytecode.

Command:

        javac Hello.java

This normally produces:

        Hello.class

The .class file contains Java bytecode.


------------------------------------------------------------
4. JDK, JRE AND JVM
------------------------------------------------------------

There are three important terms when learning Java:

JVM
JRE
JDK


JVM — JAVA VIRTUAL MACHINE
--------------------------

JVM is responsible for executing Java bytecode.

It provides the environment required to run Java programs.

Main responsibilities include:

- Loading classes
- Verifying bytecode
- Executing bytecode
- Managing memory
- Working with garbage collection
- Providing runtime support


JRE — JAVA RUNTIME ENVIRONMENT
------------------------------

JRE provides the environment required to run Java
applications.

It contains:

        JVM + Java runtime libraries


JDK — JAVA DEVELOPMENT KIT
---------------------------

JDK is used for developing Java applications.

It contains tools required to write, compile, debug and run
Java programs.

Important JDK tools include:

        javac
        java
        jar
        javadoc


Relationship:

        JDK
         |
         v
        JRE
         |
         v
        JVM

### 2. `data_types.java`

This one is **actual Java code**, covering all 8 primitive types and several reference/non-primitive types.

```java
/*
 * ============================================================
 *                    JAVA DATA TYPES
 * ============================================================
 *
 * Java data types are mainly divided into two categories:
 *
 * 1. Primitive Data Types
 * 2. Non-Primitive / Reference Data Types
 *
 *
 * ============================================================
 * PRIMITIVE DATA TYPES
 * ============================================================
 *
 * Java has 8 primitive data types:
 *
 * 1. byte
 * 2. short
 * 3. int
 * 4. long
 * 5. float
 * 6. double
 * 7. char
 * 8. boolean
 *
 *
 * Primitive types store simple values directly.
 *
 *
 * ============================================================
 * 1. BYTE
 * ============================================================
 *
 * Size: 8 bits
 *
 * Range:
 * -128 to 127
 *
 * Used when small integer values are sufficient and memory
 * efficiency matters.
 *
 * Real-world example:
 * Sensor data or compact numeric data.
 *
 * ============================================================
 */

public class data_types {

    public static void main(String[] args) {

        // ----------------------------------------------------
        // 1. BYTE
        // ----------------------------------------------------

        byte age = 19;

        System.out.println("Byte value: " + age);


        /*
         * ----------------------------------------------------
         * 2. SHORT
         * ----------------------------------------------------
         *
         * Size: 16 bits
         *
         * Range:
         * -32,768 to 32,767
         *
         * Used for integer values larger than byte but smaller
         * than int.
         */

        short temperature = 25000;

        System.out.println("Short value: " + temperature);


        /*
         * ----------------------------------------------------
         * 3. INT
         * ----------------------------------------------------
         *
         * Size: 32 bits
         *
         * Range:
         * -2,147,483,648 to 2,147,483,647
         *
         * int is the most commonly used integer type in Java.
         *
         * Real-world examples:
         * - Age
         * - Marks
         * - Quantity
         * - Number of students
         * - Product IDs
         */

        int students = 500;

        System.out.println("Int value: " + students);


        /*
         * ----------------------------------------------------
         * 4. LONG
         * ----------------------------------------------------
         *
         * Size: 64 bits
         *
         * Used when int is not large enough.
         *
         * An L is normally added to a long literal.
         */

        long population = 3000000000L;

        System.out.println("Long value: " + population);


        /*
         * ----------------------------------------------------
         * 5. FLOAT
         * ----------------------------------------------------
         *
         * Size: 32 bits
         *
         * Used for decimal numbers when single precision is
         * sufficient.
         *
         * Java requires an f or F suffix for float literals.
         */

        float height = 5.5f;

        System.out.println("Float value: " + height);


        /*
         * ----------------------------------------------------
         * 6. DOUBLE
         * ----------------------------------------------------
         *
         * Size: 64 bits
         *
         * double provides more precision than float.
         *
         * It is the usual choice for general-purpose
         * floating-point calculations.
         */

        double salary = 55000.75;

        System.out.println("Double value: " + salary);


        /*
         * ----------------------------------------------------
         * 7. CHAR
         * ----------------------------------------------------
         *
         * Size: 16 bits
         *
         * Stores a single UTF-16 code unit.
         *
         * A char is written using single quotes.
         */

        char grade = 'A';

        System.out.println("Char value: " + grade);


        /*
         * ----------------------------------------------------
         * 8. BOOLEAN
         * ----------------------------------------------------
         *
         * Stores either:
         *
         * true
         * false
         *
         * Used for logical conditions.
         *
         * Real-world examples:
         * - Login successful?
         * - Account active?
         * - User is administrator?
         * - Payment completed?
         */

        boolean isStudent = true;

        System.out.println("Boolean value: " + isStudent);


        /*
         * ====================================================
         *              NON-PRIMITIVE / REFERENCE TYPES
         * ====================================================
         *
         * Reference types store references to objects rather
         * than being one of Java's eight primitive types.
         *
         * Important reference types include:
         *
         * 1. String
         * 2. Arrays
         * 3. Classes
         * 4. Objects
         * 5. Interfaces
         * 6. Enums
         * 7. Records
         */


        /*
         * ----------------------------------------------------
         * 1. STRING
         * ----------------------------------------------------
         *
         * String is a class used to represent text.
         *
         * Example:
         */

        String name = "Anmol Sapkota";

        System.out.println("String value: " + name);


        /*
         * ----------------------------------------------------
         * 2. ARRAY
         * ----------------------------------------------------
         *
         * An array stores multiple values of the same type.
         *
         * Array indexing starts from 0.
         */

        int[] marks = {80, 75, 90, 85, 88};

        System.out.println("First mark: " + marks[0]);

        System.out.println("All marks:");

        for (int mark : marks) {

            System.out.println(mark);
        }


        /*
         * ----------------------------------------------------
         * 3. CLASS / OBJECT
         * ----------------------------------------------------
         *
         * A class is a blueprint.
         *
         * An object is an instance of a class.
         */

        Student student = new Student();

        student.name = "Anmol";
        student.age = 19;

        System.out.println("Student name: " + student.name);
        System.out.println("Student age: " + student.age);


        /*
         * ----------------------------------------------------
         * 4. ENUM
         * ----------------------------------------------------
         *
         * An enum represents a fixed set of constants.
         *
         * Example:
         *
         * PENDING
         * APPROVED
         * REJECTED
         */

        Status status = Status.APPROVED;

        System.out.println("Status: " + status);


        /*
         * ----------------------------------------------------
         * 5. INTERFACE REFERENCE
         * ----------------------------------------------------
         *
         * An interface defines a contract that classes can
         * implement.
         */

        Payment payment = new OnlinePayment();

        payment.pay();


        /*
         * ====================================================
         *                  SUMMARY
         * ====================================================
         */

        System.out.println("\n==============================");
        System.out.println("Java Data Types");
        System.out.println("==============================");

        System.out.println("Primitive:");
        System.out.println("byte");
        System.out.println("short");
        System.out.println("int");
        System.out.println("long");
        System.out.println("float");
        System.out.println("double");
        System.out.println("char");
        System.out.println("boolean");

        System.out.println("\nReference / Non-Primitive:");
        System.out.println("String");
        System.out.println("Array");
        System.out.println("Class / Object");
        System.out.println("Interface");
        System.out.println("Enum");
        System.out.println("Record");
    }


    /*
     * ========================================================
     * CLASS USED FOR OBJECT EXAMPLE
     * ========================================================
     */

    static class Student {

        String name;
        int age;
    }


    /*
     * ========================================================
     * ENUM EXAMPLE
     * ========================================================
     */

    enum Status {

        PENDING,
        APPROVED,
        REJECTED
    }


    /*
     * ========================================================
     * INTERFACE EXAMPLE
     * ========================================================
     */

    interface Payment {

        void pay();
    }


    /*
     * ========================================================
     * CLASS IMPLEMENTING INTERFACE
     * ========================================================
     */

    static class OnlinePayment implements Payment {

        @Override
        public void pay() {

            System.out.println("Payment processed.");
        }
    }
}


/*
 * ============================================================
 *                    QUICK REFERENCE
 * ============================================================
 *
 * Primitive:
 *
 * byte       -> small integer
 * short      -> medium integer
 * int        -> general integer
 * long       -> large integer
 * float      -> decimal, single precision
 * double     -> decimal, double precision
 * char       -> single UTF-16 code unit
 * boolean    -> true / false
 *
 *
 * Reference / Non-Primitive:
 *
 * String     -> text
 * Array      -> collection of same-type elements
 * Class      -> blueprint for objects
 * Object     -> instance of a class
 * Interface  -> contract/type
 * Enum       -> fixed set of constants
 * Record     -> concise data-carrier class
 *
 * ============================================================
 */
