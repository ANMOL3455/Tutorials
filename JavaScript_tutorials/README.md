# JavaScript Programming Tutorials

A practical JavaScript learning repository from absolute beginner fundamentals through intermediate programming, browser APIs, DOM manipulation, asynchronous JavaScript, modules, modern ES features, and small projects.

## Topics
1. Basics
2. Variables and data types
3. Operators
4. Conditionals
5. Loops
6. Functions
7. Arrays
8. Objects
9. Strings and numbers
10. Error handling
11. Scope, closures and callbacks
12. Modern ES6+ features
13. DOM and browser APIs
14. Events and forms
15. Async JavaScript and Fetch API
16. JSON and localStorage
17. Modules and npm basics
18. OOP and classes
19. Intermediate projects

## Linux
Check Node.js:
```bash
node --version
```
Run a file:
```bash
node filename.js
```
For browser examples, open the corresponding HTML file in a browser.

## Learning order
Follow the folders from 01 to 19. Do not only read the examples: type them yourself, change values, break them, fix them, and build your own variations.

## Philosophy
Learn → Practice → Build → Improve
